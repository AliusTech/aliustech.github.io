Cross-Platform Support

Alius Agent Team is built on Tauri 2, truly achieving cross-platform support. Whether you use a desktop computer, tablet, phone, or Apple Watch, you can get a consistent and optimized user experience.

Desktop Experience

Windows

Features

  • Native Appearance: Follows Windows 11 Fluent Design design guidelines
  • System Integration:
    • Start menu integration
    • Taskbar tray icon
    • System notification center integration
    • Right-click menu extension
  • Keyboard Shortcuts: Full keyboard shortcut support
  • Multi-Window: Supports multi-window operations
  • System Theme: Auto-adapts to system theme (light/dark)

Installation Methods

sudo apt-get install -f

sudo rpm -ivh alius-agent-team-x.x.x.x86_64.rpm

Data Synchronization

Cross-Device Synchronization

Alius Agent Team synchronizes data in real-time across all devices:

  • Agent Configuration: Stay up-to-date on all devices
  • Task Status: Real-time synchronization of task status changes
  • Team Information: Real-time synchronization of team members and permissions
  • User Preferences: Interface settings and preference synchronization

Synchronization Mechanism

Real-Time Synchronization

  • WebSocket: Establish persistent connection, push changes in real-time
  • Conflict Resolution: Use “last write wins” strategy for simple conflicts
  • Version Control: Complex conflicts resolved through version control

Offline Support

  • Offline Cache: Recently accessed data cached locally
  • Operation Queue: Queue operations when offline, sync when online
  • Incremental Sync: Only sync changed data, save bandwidth

Sync Settings

Configure sync behavior in user settings:

  • Auto Sync: Automatically sync data (recommended)
  • Manual Sync: Only sync when clicking sync button
  • Wi-Fi Only Sync: Only sync on Wi-Fi network
  • Sync Frequency: Set auto-sync frequency

Cross-Platform Development Technology

Tauri 2 Architecture

Alius Agent Team uses Tauri 2 for cross-platform development:

Frontend (React 19 + TypeScript)
        ↓
    Tauri Core (Rust)
        ↓
  Platform Abstraction Layer
        ↓
  Windows / macOS / Linux / iOS

Advantages

  • Small Size: App size typically < 10MB
  • High Performance: Rust backend provides near-native performance
  • Secure: Rust’s memory safety guarantees
  • Low Resource Usage: Much lower memory and CPU usage than Electron

Code Sharing Strategy

src/
├── core/              # Pure logic code (cross-platform shared)
│   ├── types/        # Type definitions
│   ├── utils/        # Utility functions
│   └── services/     # Business logic
├── platform/
│   ├── desktop/     # Desktop-specific code
│   ├── mobile/      # Mobile-specific code
│   └── watch/       # Watch-specific code
└── shared/           # Shared UI components

Code Sharing Ratio

  • Logic Code: 95% shared
  • UI Components: 70% shared
  • Platform-Specific Code: 5-30%

Troubleshooting

Sync Issues

Problem: Data updated on one device doesn’t show on other devices

Solutions:

  1. Check network connection
  2. Manually trigger sync
  3. Restart the app
  4. If problem persists, contact support team

Notification Issues

Problem: Not receiving push notifications on mobile devices

Solutions:

  1. Check system notification settings
  2. Ensure app has permission to send notifications
  3. Check Do Not Disturb settings
  4. Re-login to account

Performance Issues

Problem: App runs slowly on some devices

Solutions:

  1. Close unnecessary Agents
  2. Clear cache
  3. Update to latest version
  4. If problem persists, contact support team
