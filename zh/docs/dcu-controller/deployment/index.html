首页 / 文档 / DCU 控制器 / 部署指南

本指南详细介绍了将 Alius DCU 域控制器部署到实际机器人系统中的完整流程。请按照本章节的步骤进行操作，以确保系统安全、稳定地运行。

安全注意事项

在开始部署之前，请务必阅读以下安全注意事项：

  • 电源安全：确保输入电压在 9-36 VDC 范围内，接线前确认电源已关闭。
  • 静电防护：接触 DCU 板卡前，请佩戴防静电手环或触摸接地金属物体释放静电。
  • 隔离保护：CAN 和 RS-485 接口已具备电气隔离，但仍需确保系统接地良好。
  • 散热管理：DCU 采用被动散热设计，安装时请确保散热片周围有足够的空气流动空间。

机械安装

安装位置选择

选择 DCU 的安装位置时，应考虑以下因素：

  1. 散热空间：DCU 顶部（散热片侧）应保留至少 20 mm 的散热空间，确保空气自然对流。
  2. 振动隔离：如安装在振动较大的位置（如机器人关节附近），建议使用橡胶减震垫。
  3. 防水防尘：DCU 本身不具备防水功能，如在户外或潮湿环境使用，需加装防护外壳。
  4. 维护便利性：安装位置应便于接入调试接口和指示灯观察。

安装步骤

  1. 在机器人机箱或安装板上标记 4 个 M3 安装孔的位置。
  2. 使用 3 mm 钻头钻孔，并攻 M3 螺纹（或使用螺母固定）。
  3. 在 DCU 与安装板之间放置绝缘垫片（随产品提供）。
  4. 使用 4 颗 M3 螺丝将 DCU 固定在安装板上，扭矩控制在 0.5-0.8 N·m。
  5. 检查安装是否牢固，板卡是否平整。

电气连接

电源连接

DCU 的电源输入采用 2-pin 接线端子（间距 3.81 mm）：

  1. 将电源线剥去约 7 mm 绝缘皮。
  2. 将电源正极（通常为红色）插入 VIN 端子，逆时针拧紧螺丝。
  3. 将电源负极（通常为黑色）插入 GND 端子，逆时针拧紧螺丝。
  4. 轻轻拉动电源线，确认连接可靠。
  5. 使用万用表测量端子处的电压，确认极性正确且电压在允许范围内。

注意：DCU 具备反极性保护，但错误接线仍可能导致系统不稳定，请务必仔细核对。

CAN-FD 总线连接

DCU 提供 2 路 CAN-FD 接口，每路使用 3-pin 接线端子：

端子定义：

  • Pin 1：CANH（高电平信号线）
  • Pin 2：CANL（低电平信号线）
  • Pin 3：GND（信号地）

连接步骤：

  1. 使用双绞线（推荐 CAT5e 或更高规格）连接 CANH 和 CANL。
  2. 总线两端需各并联一个 120Ω 终端电阻（DCU 板载可配置终端电阻）。
  3. 将所有节点的 GND 连接在一起，但不应与电源地混淆。
  4. 检查总线拓扑，推荐使用菊花链（daisy chain）拓扑，避免星型连接。

RS-485 总线连接

DCU 提供 2 路 RS-485 接口，每路使用 3-pin 接线端子：

端子定义：

  • Pin 1：A（正信号线，对应 Data+ / D+）
  • Pin 2：B（负信号线，对应 Data- / D-）
  • Pin 3：GND（信号地）

连接注意事项：

  • RS-485 总线同样推荐使用双绞线。
  • 总线两端需并联 120Ω 终端电阻。
  • 接地线（GND）可减少共模干扰，提高通信可靠性。

EtherCAT 网络连接

DCU 的 2 路 EtherCAT 接口支持菊花链连接：

  1. 使用标准 CAT5e 或更高规格以太网线缆。
  2. 将 DCU 的 EtherCAT Port 0 连接到第一个 EtherCAT 从站。
  3. 从第一个从站的出口连接到下一个从站，以此类推。
  4. 在系统配置中正确设置从站数量和拓扑结构。

系统配置

首次启动配置

  1. 接通电源，通过调试串口登录系统。
  2. 修改默认密码：
passwd
  1. 配置主机名：
sudo hostnamectl set-hostname dcu-robot-001
  1. 配置网络（静态 IP 推荐用于机器人系统）：
sudo nano /etc/network/interfaces

# 添加以下内容
auto eth0
iface eth0 inet static
    address 192.168.1.100
    netmask 255.255.255.0
    gateway 192.168.1.1
  1. 配置时区和时间同步：
sudo timedatectl set-timezone Asia/Shanghai
sudo apt install -y chrony
sudo systemctl enable chrony

RTOS 协处理器配置

DCU 的 RTOS 协处理器负责实时控制任务，需要进行以下配置：

  1. 编辑 RTOS 配置文件：
sudo nano /opt/aliu/rtos/config.json
  1. 根据应用需求配置控制周期、任务优先级等参数。
  2. 重启 RTOS 服务以应用配置：
sudo systemctl restart aliu-rtos

应用部署

部署 Alius 机器人控制软件栈

Alius 提供了完整的机器人控制软件栈，可通过以下方式部署：

# 添加 Alius 软件源
curl -fsSL https://packages.aliu.tech/gpg | sudo apt-key add -
echo "deb https://packages.aliu.tech dcu main" | sudo tee /etc/apt/sources.list.d/aliu.list

# 安装核心软件包
sudo apt update
sudo apt install -y aliu-core aliu-can aliu-ethercat

配置自动启动

在生产环境中，通常需要将控制软件配置为系统服务，实现开机自动启动：

# 创建 systemd 服务文件
sudo nano /etc/systemd/system/robot-control.service

# 文件内容如下：
# [Unit]
# Description=Alius Robot Control Service
# After=network.target aliu-rtos.service
#
# [Service]
# Type=simple
# User=aliu
# WorkingDirectory=/opt/robot
# ExecStart=/opt/robot/control_node
# Restart=always
# RestartSec=5
#
# [Install]
# WantedBy=multi-user.target

# 启用服务
sudo systemctl enable robot-control.service
sudo systemctl start robot-control.service

部署检查清单

在完成部署后，请使用以下检查清单验证系统状态：

  • 电源输入电压在允许范围内
  • 所有接口连接可靠，螺丝已紧固
  • 系统正常启动，无异常日志
  • 网络连接正常，延迟 < 1 ms（局域网）
  • CAN-FD 总线通信正常，无错误帧
  • RS-485 通信正常
  • EtherCAT 从站全部在线
  • RTOS 协处理器运行正常
  • NPU 推理功能正常
  • 控制软件开机自动启动
  • 系统时间已同步
  • 散热片温度 < 70°C（满载）
