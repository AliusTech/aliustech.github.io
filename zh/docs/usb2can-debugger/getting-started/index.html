快速入门指南

本指南将帮助您快速设置和使用 Alius USB2CAN 双路调试器。按照本指南的步骤操作，您将在几分钟内完成硬件连接、驱动安装并进行第一次 CAN 总线通信测试。

硬件准备

在开始之前，请确保您已准备好以下物品：

  • Alius USB2CAN 双路调试器主机
  • USB A 到 B 型连接线（通常随设备提供）
  • DB9 转接线或 CAN 总线连接线（根据您的应用需求）
  • 目标 CAN 总线设备或网络

步骤 1：硬件连接

1.1 连接 USB 接口

将 USB 连接线的一端（Type B）插入 Alius USB2CAN 调试器的 USB 接口，另一端（Type A）插入计算机的 USB 端口。此时，设备上的电源指示灯应亮起，表示设备已通电。

1.2 连接 CAN 总线

Alius USB2CAN 调试器使用标准的 DB9 连接器（Female）。根据您的应用需求，正确连接 CAN 总线：

DB9 引脚定义：

引脚信号描述
1-保留
2CAN-L CH1通道 1 CAN 低
3CAN-H CH1通道 1 CAN 高
4-保留
5GND信号地
6-保留
7CAN-H CH2通道 2 CAN 高
8CAN-L CH2通道 2 CAN 低
9-保留

连接方式：

  1. 将 CAN 总线的高线（CAN-H）连接到 DB9 连接器的引脚 3（通道 1）或引脚 7（通道 2）
  2. 将 CAN 总线的低线（CAN-L）连接到 DB9 连接器的引脚 2（通道 1）或引脚 8（通道 2）
  3. 确保信号地（GND）正确连接，以提高通信稳定性

重要提示： 在连接 CAN 总线之前，请确保设备的电气隔离功能已启用，并仔细检查接线，避免短路或接错线导致设备损坏。

步骤 2：驱动安装

2.1 Windows 系统

  1. 将设备连接到计算机后，Windows 会自动检测到新硬件
  2. 如果系统未能自动安装驱动程序，请访问 Alius 官方网站下载最新的 Windows 驱动程序
  3. 运行安装程序，按照提示完成安装
  4. 安装完成后，在”设备管理器”中查看”端口（COM 和 LPT）“，应能看到 Alius USB2CAN 设备对应的 COM 端口

支持的操作系统：

  • Windows 2000
  • Windows XP
  • Windows Vista
  • Windows 7
  • Windows 10
  • Windows 11

2.2 Linux 系统

  1. 大多数现代 Linux 发行版会自动识别并加载 USB 串口驱动程序
  2. 连接设备后，使用以下命令查看设备节点： 
    dmesg | tail
ls /dev/ttyUSB*
  3. 如果需要，可以安装额外的工具以支持 CANAL API

步骤 3：配置 CAN 通道

3.1 设置波特率

Alius USB2CAN 调试器支持 10 Kbit/s 到 1000 Kbit/s 的波特率。根据您的 CAN 总线网络设置，选择正确的波特率。常用的波特率包括：

  • 10 Kbit/s：用于长距离、低速率通信
  • 125 Kbit/s：用于某些汽车应用
  • 250 Kbit/s：用于某些工业应用
  • 500 Kbit/s：用于高速汽车网络通信
  • 1000 Kbit/s：用于高速应用

3.2 配置过滤器（可选）

如果只需要监控特定的 CAN 报文，可以配置硬件过滤器。这可以减轻处理器的负担，提高系统的实时性。

步骤 4：测试通信

4.1 使用测试软件

  1. 打开 Alius 提供的测试软件或第三方 CAN 总线分析工具
  2. 选择对应的 COM 端口
  3. 配置波特率和其他参数
  4. 打开 CAN 通道
  5. 开始监控 CAN 总线流量

4.2 发送测试报文

  1. 在测试软件中，配置一个测试报文（例如，ID 为 0x100 的标准帧）
  2. 点击”发送”按钮
  3. 在接收窗口中应能看到发送的报文
  4. 如果有其他 CAN 节点，也能看到来自这些节点的报文

4.3 验证指示灯

Alius USB2CAN 调试器配备了状态指示灯，用于显示设备的工作状态：

  • 电源指示灯（PWR）：亮起表示设备已通电
  • CAN 活动指示灯（ACT）：闪烁表示有 CAN 总线活动
  • 错误指示灯（ERR）：亮起表示检测到总线错误

常见问题排查

问题 1：设备未被识别

解决方法：

  • 检查 USB 连接线是否完好
  • 尝试更换 USB 端口
  • 重新安装驱动程序

问题 2：无法接收 CAN 报文

解决方法：

  • 检查 CAN 总线连接是否正确
  • 确认波特率设置是否正确
  • 检查 CAN 总线是否处于活动状态（有其他节点在发送报文）
  • 检查终端电阻是否正确配置

问题 3：通信不稳定

解决方法：

  • 检查接地是否良好
  • 缩短连接线长度
  • 降低波特率测试
  • 检查是否有电磁干扰

下一步

完成快速入门后，您可以：

  • 阅读《技术规格》文档，了解设备的详细技术参数
  • 阅读《API 文档》，学习如何通过编程接口控制设备
  • 阅读《驱动程序》文档，了解如何在不同操作系统中使用设备

祝您使用愉快！
