驱动程序安装与配置

Alius USB2CAN 双路调试器需要正确的驱动程序才能在计算机上正常工作。本文档详细介绍了在 Windows 和 Linux 操作系统上安装和配置驱动程序的步骤，帮助您快速完成驱动设置。

Windows 驱动程序

支持的操作系统

Alius USB2CAN 调试器的 Windows 驱动程序支持以下操作系统：

  • Windows 2000（SP4 或更高版本）
  • Windows XP（SP2 或更高版本）
  • Windows Vista
  • Windows 7
  • Windows 10
  • Windows 11

自动安装（推荐）

在大多数情况下，Windows 会自动检测并安装 Alius USB2CAN 调试器的驱动程序。

步骤：

  1. 将 Alius USB2CAN 调试器连接到计算机的 USB 端口
  2. Windows 会自动检测到新硬件，并尝试安装驱动程序
  3. 等待 Windows 完成驱动程序安装
  4. 打开”设备管理器”，查看”端口（COM 和 LPT）“，确认设备已正确安装

手动安装

如果 Windows 未能自动安装驱动程序，您可以手动安装。

步骤：

  1. 访问 Alius 官方网站，下载最新的 Windows 驱动程序包
  2. 解压驱动程序包到一个临时目录
  3. 将 Alius USB2CAN 调试器连接到计算机的 USB 端口
  4. 打开”设备管理器”（右键点击”此电脑” → “管理” → “设备管理器”）
  5. 在设备列表中，找到带有黄色感叹号的设备（通常显示为”未知设备”或”USB 串行设备”）
  6. 右键点击该设备，选择”更新驱动程序”
  7. 选择”浏览我的计算机以查找驱动程序”
  8. 点击”浏览”，选择解压后的驱动程序目录
  9. 点击”下一步”，Windows 将开始安装驱动程序
  10. 如果弹出”Windows 无法验证此驱动程序软件的发布者”警告，点击”仍要继续”
  11. 等待安装完成
  12. 安装完成后，在”设备管理器”的”端口（COM 和 LPT）“中，应能看到 Alius USB2CAN 设备对应的 COM 端口

驱动程序验证

安装完成后，请验证驱动程序是否正确安装。

步骤：

  1. 打开”设备管理器”
  2. 展开”端口（COM 和 LPT）”
  3. 找到 Alius USB2CAN 设备（通常显示为”Alius USB2CAN Serial Port (COMx)”）
  4. 右键点击该设备，选择”属性”
  5. 在”常规”选项卡中，确认设备状态为”此设备正常工作”
  6. 在”驱动程序”选项卡中，查看驱动程序版本和日期

驱动程序更新

当有新的驱动程序版本发布时，建议您更新到最新版本，以获得更好的性能和稳定性。

步骤：

  1. 访问 Alius 官方网站，下载最新的 Windows 驱动程序包
  2. 解压驱动程序包
  3. 打开”设备管理器”
  4. 找到 Alius USB2CAN 设备
  5. 右键点击该设备，选择”更新驱动程序”
  6. 按照手动安装的步骤，选择新的驱动程序目录
  7. 完成更新

驱动程序卸载

如果您需要卸载驱动程序（例如，更换计算机或排除故障），请按照以下步骤操作。

步骤：

  1. 打开”设备管理器”
  2. 找到 Alius USB2CAN 设备
  3. 右键点击该设备，选择”卸载设备”
  4. 在弹出的对话框中，勾选”删除此设备的驱动程序软件”（可选）
  5. 点击”卸载”
  6. 断开 Alius USB2CAN 调试器与计算机的连接

Linux 驱动程序

支持的操作系统

Alius USB2CAN 调试器的 Linux 驱动程序支持大多数主流的 Linux 发行版，包括：

  • Ubuntu（16.04 及更高版本）
  • Debian（8 及更高版本）
  • Fedora（24 及更高版本）
  • CentOS（7 及更高版本）
  • Arch Linux
  • openSUSE

自动识别

在大多数现代 Linux 发行版中，Alius USB2CAN 调试器会被自动识别为 USB 串口设备，无需手动安装驱动程序。

步骤：

  1. 将 Alius USB2CAN 调试器连接到计算机的 USB 端口
  2. 打开终端
  3. 使用以下命令查看内核消息： 
    dmesg | tail
    您应能看到类似以下的输出： 
    [ 1234.567890] usb 3-1: new full-speed USB device number 5 using xhci_hcd
[ 1234.678901] usb 3-1: New USB device found, idVendor=1234, idProduct=5678
[ 1234.678902] usb 3-1: New USB device strings: Mfr=1, Product=2, SerialNumber=3
[ 1234.678903] usb 3-1: Product: Alius USB2CAN
[ 1234.678904] usb 3-1: Manufacturer: Alius
[ 1234.678905] usb 3-1: SerialNumber: 1234567890
[ 1234.789012] usbcore: registered new interface driver usbserial
[ 1234.789013] usbcore: registered new interface driver usbserial_generic
[ 1234.789014] usbserial: USB Serial support registered for generic
[ 1234.789123] usbcore: registered new interface driver ftdi_sio
[ 1234.789124] usbserial: USB Serial support registered for FTDI USB Serial Device
[ 1234.789234] ftdi_sio 3-1:1.0: FTDI USB Serial Device converter detected
[ 1234.789345] usb 3-1: FTDI USB Serial Device converter now attached to ttyUSB0
  4. 使用以下命令查看设备节点： 
    ls /dev/ttyUSB*
    您应能看到类似 /dev/ttyUSB0 的设备节点

权限配置

在 Linux 系统中，访问串口设备需要适当的权限。默认情况下，只有 root 用户和 dialout 组的成员可以访问串口设备。

方法 1：将用户添加到 dialout 组（推荐）

  1. 打开终端
  2. 使用以下命令将当前用户添加到 dialout 组： 
    sudo usermod -a -G dialout $USER
  3. 注销并重新登录，使组更改生效

方法 2：使用 udev 规则

  1. 创建 udev 规则文件： 
    sudo nano /etc/udev/rules.d/99-alius-usb2can.rules
  2. 在文件中添加以下内容： 
    SUBSYSTEM=="tty", ATTRS{idVendor}=="1234", ATTRS{idProduct}=="5678", MODE="0666"
    注意：请将 1234 和 5678 替换为 Alius USB2CAN 调试器的实际 Vendor ID 和 Product ID。您可以使用 lsusb 命令查看这些信息。
  3. 保存并关闭文件
  4. 重新加载 udev 规则： 
    sudo udevadm control --reload-rules
sudo udevadm trigger
  5. 断开并重新连接 Alius USB2CAN 调试器

CANAL API 安装

要在 Linux 上使用 CANAL API，您需要安装 CANAL 库。

步骤：

  1. 下载 CANAL API 源代码
  2. 解压源代码包
  3. 打开终端，进入源代码目录
  4. 编译并安装： 
    make
sudo make install
  5. 更新动态链接库缓存： 
    sudo ldconfig

故障排除

问题 1：设备未被识别

解决方法：

  • 检查 USB 连接线是否完好
  • 尝试连接到不同的 USB 端口
  • 检查内核日志（dmesg）以查看错误信息
  • 确认内核已加载正确的驱动程序模块（ftdi_sio）

问题 2：权限被拒绝

解决方法：

  • 将用户添加到 dialout 组
  • 使用 sudo 运行应用程序
  • 配置 udev 规则

问题 3：设备节点不存在

解决方法：

  • 检查内核日志以查看设备是否被识别
  • 手动加载驱动程序模块：sudo modprobe ftdi_sio
  • 重新连接设备

应用场景示例

使用 MiniCAN 监控 CAN 总线

MiniCAN 是一款流行的 CAN 总线监控工具，支持 Alius USB2CAN 调试器。

步骤：

  1. 下载并安装 MiniCAN
  2. 连接 Alius USB2CAN 调试器
  3. 启动 MiniCAN
  4. 选择对应的 COM 端口或设备节点
  5. 配置波特率
  6. 开始监控

使用 Python-CAN 库

Python-CAN 是一个功能强大的 Python 库，用于 CAN 总线通信。

安装：

pip install python-can

示例代码：

import can

# 创建总线
bus = can.interface.Bus(bustype='serial', channel='/dev/ttyUSB0', bitrate=500000)

# 发送报文
msg = can.Message(arbitration_id=0x100, data=[0x01, 0x02, 0x03, 0x04, 0x05, 0x06, 0x07, 0x08])
bus.send(msg)

# 接收报文
for msg in bus:
    print(f"ID: {msg.arbitration_id}, Data: {msg.data}")
