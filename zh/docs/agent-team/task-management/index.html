任务管理

任务管理是 Alius Agent Team 的核心功能之一。通过高效的任劾分配和跟踪机制，您可以充分利用多个 Agent 的协同能力，完成复杂的工作流程。

任务概念

什么是任务

在 Alius Agent Team 中，任务（Task） 是分配给 Agent 执行的工作单元。一个任务可以是一个简单的问题、一个复杂的多步骤流程，或者一个需要长时间运行的后台作业。

任务类型

系统支持多种任务类型：

类型描述示例
即时任务立即执行的任务”帮我写一段 Python 代码”
定时任务在指定时间执行”每天早上 9 点生成昨日报告”
循环任务按设定的周期重复执行”每小时检查一次服务器状态”
依赖任务等待其他任务完成后执行”在数据处理完成后，生成可视化报告”
批处理任务批量处理多个相似任务”为这 100 张图片生成描述”

创建任务

通过界面创建任务

步骤 1：选择目标 Agent

您可以通过以下方式选择 Agent：

  • 在 Agent 列表中直接选择
  • 让系统自动选择最合适的 Agent
  • 创建任务后再分配 Agent

步骤 2：填写任务信息

  • 标题：简短描述任务（必填）
  • 描述：详细说明任务要求（必填）
  • 优先级：设置任务优先级
    • 紧急：需要立即处理
    • 高：重要且时间敏感
    • 中：正常优先级
    • 低：不紧急的任务
  • 截止时间：设置任务完成的截止时间（可选）
  • 标签：为任务添加标签，便于分类和搜索

步骤 3：高级选项配置

  • 上下文文件：上传相关文件作为任务上下文
  • 输出格式：指定输出格式要求
  • 回调 URL：任务完成后通知的 URL
  • 超时设置：设置任务执行超时时间

步骤 4：提交任务

点击”提交”按钮，任务将被发送到选定的 Agent。

通过 API 创建任务

curl -X POST https://api.alius.ai/v1/tasks \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "代码审查",
    "description": "审查以下 Pull Request 的代码质量",
    "agentId": "agent_12345",
    "priority": "high",
    "deadline": "2024-01-20T17:00:00Z",
    "attachments": [
      {
        "type": "url",
        "url": "https://github.com/example/repo/pull/123"
      }
    ]
  }'

批量创建任务

当需要创建多个相似任务时，可以使用批量创建功能：

  1. 准备包含任务信息的 CSV 或 JSON 文件
  2. 在任务列表页面，点击”批量操作” > “导入任务”
  3. 上传文件并映射字段
  4. 确认导入

示例批量任务文件（JSON）：

[
  {
    "title": "分析数据文件 1",
    "description": "分析 data1.csv 的数据分布",
    "agentId": "agent_12345"
  },
  {
    "title": "分析数据文件 2",
    "description": "分析 data2.csv 的数据分布",
    "agentId": "agent_12345"
  }
]

任务分配

自动分配

Alius Agent Team 提供智能任务分配功能：

负载均衡分配

系统根据以下因素自动选择最合适的 Agent：

  • Agent 的当前负载
  • Agent 的类型和能力匹配度
  • Agent 的历史性能
  • 任务的优先级和要求

规则基础分配

您可以设置分配规则：

规则 1：代码生成任务 -> 分配给标签为"codegen"的 Agent
规则 2：高优先级任务 -> 分配给负载低于 50% 的 Agent
规则 3：大数据任务 -> 分配给内存大于 4GB 的 Agent

手动分配

您也可以手动将任务分配给特定 Agent：

  1. 在任务列表中找到未分配的任务
  2. 点击”分配”按钮
  3. 从可用 Agent 列表中选择
  4. 确认分配

重新分配

如果任务分配不当，您可以重新分配：

  1. 找到要重新分配的任务
  2. 点击”更多操作” > “重新分配”
  3. 选择新的 Agent
  4. 可选：添加重新分配原因
  5. 确认重新分配

任务跟踪

任务状态

任务在其生命周期中会经历以下状态：

待处理 (Pending)
    ↓
进行中 (Running)
    ↓
    ├── 已完成 (Completed)
    ├── 失败 (Failed)
    └── 已取消 (Cancelled)

状态说明

  • 待处理：任务已创建，等待 Agent 接收
  • 进行中：Agent 正在执行任务
  • 已完成：任务成功完成
  • 失败：任务执行失败
  • 已取消：任务被用户取消

实时进度跟踪

进度指示器

对于长时间运行的任务，系统提供实时进度更新：

[=======>     ] 65% - 正在处理第 13/20 个文件
预计剩余时间：约 2 分钟

任务日志

查看任务的详细执行日志：

  1. 点击任务查看详情
  2. 选择”执行日志”标签
  3. 查看实时或历史日志
[步骤 1/3] 正在读取输入文件... ✓ 完成 (12ms)
[步骤 2/3] 正在分析数据... ▶ 进行中 (45%)
[步骤 3/3] 正在生成报告... ○ 等待中

任务详情查看

点击任意任务可以查看完整详情：

  • 基本信息：标题、描述、状态、优先级等
  • 分配信息：分配给哪个 Agent、分配时间
  • 时间线：任务创建、分配、开始、完成的时间
  • 执行结果：任务输出、生成文件、错误信息等
  • 历史记录：任务的所有状态变更历史

任务调度

定时任务

创建在特定时间执行的任务：

  1. 创建新任务时，选择”定时执行”
  2. 设置执行时间
  3. 可选：设置执行后是否重复

示例：

执行时间：2024-01-20 09:00:00
重复：不重复

循环任务

创建按周期重复执行的任务：

  1. 创建新任务时，选择”循环执行”
  2. 设置循环规则：
    • 按分钟：每 N 分钟执行一次
    • 按小时：每 N 小时执行一次
    • 按天：每天执行一次
    • 按周：每周指定日执行
    • 按月：每月指定日执行
    • Cron 表达式：使用标准 Cron 表达式

示例 Cron 表达式：

0 9 * * 1-5  # 每周一至周五早上 9 点执行
0 */2 * * *   # 每 2 小时执行一次
0 0 1 * *     # 每月 1 号凌晨执行

依赖任务

创建依赖于其他任务结果的任务：

  1. 创建新任务时，选择”依赖任务”
  2. 添加依赖任务：
    • 前置任务：必须完成的任务
    • 条件：前置任务的成功条件
  3. 设置依赖关系：
    • 顺序执行：A 完成后执行 B
    • 并行执行：A 和 B 都完成后执行 C
    • 条件分支：根据 A 的结果决定执行 B 或 C

任务管理操作

任务队列管理

查看队列

在”任务”页面，您可以查看：

  • 所有任务：系统中的所有任务
  • 我的任务：我创建的任务
  • 待处理：等待分配或执行的任务
  • 进行中：正在执行的任务
  • 已完成：成功完成的任务
  • 失败：执行失败的任务

队列优先级调整

  1. 在待处理任务列表中，找到要调整的任务
  2. 拖拽任务到新的位置（优先级高的在上方）
  3. 或者，修改任务的优先级字段

任务控制操作

暂停任务

对于正在运行的任务，您可以暂停：

  1. 找到正在运行的任务
  2. 点击”暂停”按钮
  3. Agent 将暂停执行，但保留当前状态
  4. 稍后可以恢复

恢复任务

恢复已暂停的任务：

  1. 找到已暂停的任务
  2. 点击”恢复”按钮
  3. Agent 将从暂停处继续执行

取消任务

取消不需要的任务：

  1. 找到要取消的任务（状态必须为”待处理”或”进行中”）
  2. 点击”取消”按钮
  3. 确认取消
  4. 如果任务正在进行中，Agent 将停止执行

重试任务

重新执行失败的任务：

  1. 找到失败的任务
  2. 点击”重试”按钮
  3. 可选：修改任务参数
  4. 任务将重新进入待处理队列

任务模板

创建模板

对于经常执行的任务，可以保存为模板：

  1. 创建一个任务并配置好所有参数
  2. 点击”保存为模板”
  3. 输入模板名称和描述
  4. 模板将保存到模板库

使用模板

从模板快速创建任务：

  1. 在任务创建页面，选择”从模板创建”
  2. 从模板库中选择模板
  3. 根据需要调整参数
  4. 提交任务

任务分析与报告

任务统计

Alius Agent Team 提供丰富的任务统计功能：

概览统计

  • 总任务数
  • 完成率
  • 平均完成时间
  • 失败率

时间范围统计

  • 今日任务量
  • 本周任务量
  • 本月任务量
  • 自定义时间范围

Agent 维度统计

  • 每个 Agent 完成的任务数
  • 每个 Agent 的平均响应时间
  • 每个 Agent 的任务成功率

导出报告

生成和导出任务报告：

  1. 在任务列表页面，点击”导出”
  2. 选择导出格式：
    • CSV
    • Excel
    • PDF
    • JSON
  3. 选择要包含的数据字段
  4. 选择时间范围
  5. 点击”导出”

最佳实践

任务分解建议

对于复杂的工作流程，建议将其分解为多个小任务：

不推荐：

任务：构建一个电商网站
（过于庞大，难以跟踪和调试）

推荐：

任务 1：设计数据库架构
任务 2：实现用户认证模块
任务 3：实现商品管理模块
任务 4：实现订单处理模块
任务 5：实现支付集成
...

优先级设置建议

  • 紧急：生产环境故障、安全漏洞等
  • 高：影响多个团队的重要功能
  • 中：正常的功能开发和优化
  • 低：实验性功能和优化建议

超时设置建议

  • 简单查询任务：30 秒 - 1 分钟
  • 代码生成任务：5 - 10 分钟
  • 数据处理任务：30 分钟 - 2 小时
  • 批量处理任务：根据数据量设置

故障排查

任务长时间处于”待处理”状态

可能原因：

  • 没有可用的 Agent
  • Agent 负载过高
  • 任务优先级设置过低

解决方法：

  1. 检查 Agent 状态
  2. 增加 Agent 数量或提高任务优先级
  3. 检查分配规则是否正确

任务执行失败

可能原因：

  • Agent 错误
  • 任务参数错误
  • 依赖服务不可用
  • 超时

解决方法：

  1. 查看任务执行日志
  2. 检查任务参数是否正确
  3. 检查依赖服务状态
  4. 增加超时时间

任务结果不符合预期

可能原因：

  • 任务描述不够清晰
  • Agent 配置不当
  • 模型选择不合适

解决方法：

  1. 优化任务描述，提供更清晰的指令
  2. 调整 Agent 配置（如温度参数）
  3. 尝试不同的模型
