Agent 管理

Agent 管理是 Alius Agent Team 的核心功能。本章详细介绍如何高效管理您的 AI Agent，从创建、配置到监控和维护。

Agent 生命周期

一个 Agent 的完整生命周期包括以下阶段：

创建 ─► 配置 ─► 部署 ─► 运行 ─► 监控 ─► 维护 ─► 更新 ─► 退役

每个阶段都有相应的管理功能和最佳实践。

创建 Agent

基础创建方式

在 Alius Agent Team 中，您可以通过多种方式创建 Agent：

方式一：快速创建

  1. 点击主界面左上角的”+“按钮
  2. 选择”创建 Agent”
  3. 填写基本信息：
    • 名称：Agent 的显示名称（必填）
    • 描述：Agent 的用途说明（可选但推荐）
    • 类型：选择预定义的 Agent 类型
  4. 点击”创建”完成

方式二：高级创建

高级创建提供更多配置选项：

  1. 在创建界面选择”高级模式”
  2. 除了基本信息外，还可以配置：
    • 运行环境：选择 Agent 运行的默认环境
    • 资源限制：设置 CPU、内存使用限制
    • 网络配置：配置网络访问权限
    • 环境变量：设置运行时的环境变量
  3. 点击”创建”完成

方式三：通过 API 创建

curl -X POST https://api.alius.ai/v1/agents \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "My Code Assistant",
    "description": "专门用于代码生成和审查的 Agent",
    "type": "codegen",
    "config": {
      "model": "gpt-4",
      "temperature": 0.2,
      "maxTokens": 4096
    }
  }'

配置 Agent

基础配置

创建 Agent 后，您可以随时修改其配置：

模型配置

  • 模型选择：选择底层 AI 模型（GPT-4、Claude 等）
  • 温度（Temperature）：控制输出的随机性
    • 0.0 - 0.3：适用于代码生成、数据分析等需要确定性的场景
    • 0.4 - 0.7：平衡创造性和准确性
    • 0.8 - 1.0：适用于创意写作等需要多样性的场景
  • 最大令牌数：单次响应的最大长度
  • Top-P：核采样参数，控制候选词的范围

提示词配置

  • 系统提示词：定义 Agent 的角色和行为准则
  • 示例对话：提供参考对话示例
  • 约束条件：设置输出格式和内容限制

高级配置

环境变量

为 Agent 设置运行时环境变量：

{
  "API_KEY": "your-api-key",
  "DEBUG": "false",
  "OUTPUT_DIR": "/path/to/output"
}

权限配置

  • 文件系统访问：控制 Agent 对文件系统的访问权限
  • 网络访问：控制 Agent 是否可以访问外部网络
  • 命令执行：控制 Agent 是否可以执行系统命令

调度配置

  • 自动启动：设置系统启动时是否自动启动 Agent
  • 定时任务：配置定时执行的任务
  • 事件触发：配置特定事件触发 Agent 执行

监控 Agent

仪表盘监控

Alius Agent Team 提供全面的 Agent 监控仪表盘：

状态监控

  • 在线状态：Agent 是否在线和运行正常
  • 健康分数：基于多个指标计算的健康分数（0-100）
  • 运行时间：Agent 的持续运行时间
  • 重启次数：Agent 的重启历史

性能监控

  • CPU 使用率：Agent 的 CPU 消耗
  • 内存使用：Agent 的内存占用
  • 响应时间：处理请求的平均响应时间
  • 吞吐量：单位时间内处理的请求数量

任务监控

  • 待处理任务：等待 Agent 处理的任务数量
  • 进行中任务：Agent 正在执行的任务
  • 已完成任务：Agent 成功完成的任务
  • 失败任务：执行失败的任务

日志查看

实时日志

在主界面选择 Agent，点击”日志”标签，可以查看实时日志：

[2024-01-15 10:23:45] [INFO] Agent started successfully
[2024-01-15 10:23:47] [INFO] Loaded configuration from config.json
[2024-01-15 10:24:12] [TASK] Received new task: task_12345
[2024-01-15 10:24:15] [TASK] Task task_12345 started
[2024-01-15 10:24:32] [TASK] Task task_12345 completed successfully

日志级别

  • ERROR：错误信息，需要立即处理
  • WARN：警告信息，需要注意
  • INFO：一般信息，记录正常操作
  • DEBUG：调试信息，用于排查问题
  • TRACE：追踪信息，最详细的日志

日志过滤和搜索

  • 按级别过滤日志
  • 按时间范围过滤日志
  • 关键词搜索
  • 导出日志到文件

维护 Agent

更新 Agent

配置更新

  1. 选择要更新的 Agent
  2. 点击”设置”图标
  3. 修改相应的配置项
  4. 点击”保存”
  5. 选择”立即重启”或”下次重启时应用”

版本更新

当 Alius Agent Team 发布新版本时：

  1. 系统会提示有可用更新
  2. 您可以选择”立即更新”或”稍后更新”
  3. 更新过程中，Agent 会短暂不可用
  4. 更新完成后，Agent 会自动重启

备份与恢复

创建备份

  1. 选择要备份的 Agent
  2. 点击”更多操作” > “备份”
  3. 选择备份内容：
    • 仅配置
    • 配置 + 会话历史
    • 完整备份（包括所有数据）
  4. 点击”创建备份”
  5. 备份文件将保存到指定位置

从备份恢复

  1. 点击”导入”或”恢复”
  2. 选择备份文件
  3. 选择恢复选项：
    • 覆盖现有 Agent
    • 创建新的 Agent
  4. 确认并等待恢复完成

克隆 Agent

快速创建配置相同的 Agent：

  1. 选择要克隆的 Agent
  2. 点击”更多操作” > “克隆”
  3. 输入新 Agent 的名称
  4. 选择要克隆的内容：
    • 仅配置
    • 配置 + 权限
    • 完整克隆
  5. 点击”克隆”

批量操作

当需要管理大量 Agent 时，批量操作功能非常有用：

批量启动/停止

  1. 在 Agent 列表中，勾选多个 Agent
  2. 点击”批量操作”
  3. 选择”启动”或”停止”
  4. 确认操作

批量配置更新

  1. 勾选多个 Agent
  2. 点击”批量操作” > “更新配置”
  3. 选择要更新的配置项
  4. 输入新的配置值
  5. 确认更新

批量分组

  1. 勾选多个 Agent
  2. 点击”批量操作” > “添加到分组”
  3. 选择现有分组或创建新分组
  4. 确认操作

最佳实践

Agent 命名规范

建议使用清晰的命名规范：

{项目}-{用途}-{环境}

示例：
- myproject-codegen-prod
- myproject-dataanalysis-dev
- chatbot-customer-service-prod

资源分配建议

  • 开发环境：1-2 个 Agent，资源限制较宽松
  • 测试环境：与生产环境相同的配置，但规模较小
  • 生产环境：
    • 关键服务：至少 2 个 Agent 实现高可用
    • 非关键服务：1 个 Agent 即可
    • 为每个 Agent 设置合理的资源限制

监控告警设置

建议设置了以下告警：

  • Agent 离线超过 5 分钟
  • 健康分数低于 70
  • CPU 使用率持续高于 80%
  • 内存使用率持续高于 90%
  • 失败任务率超过 10%

故障排查

Agent 无法启动

可能原因：

  • 配置文件格式错误
  • 端口被占用
  • 依赖服务不可用

解决方法：

  1. 检查日志中的错误信息
  2. 验证配置文件格式
  3. 检查端口占用情况
  4. 确认依赖服务正常运行

Agent 响应缓慢

可能原因：

  • 资源不足
  • 处理的任务过多
  • 网络延迟

解决方法：

  1. 检查资源使用情况
  2. 增加资源限制或扩容
  3. 优化任务分配策略
  4. 检查网络连接

Agent 反复重启

可能原因：

  • 未处理的异常
  • 内存泄漏
  • 依赖服务不稳定

解决方法：

  1. 查看错误日志
  2. 检查内存使用情况
  3. 更新到最新版本
  4. 联系技术支持
