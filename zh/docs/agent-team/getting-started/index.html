快速开始

欢迎使用 Alius Agent Team！本指南将帮助您在几分钟内完成安装、配置并开始管理您的 AI Agent。

系统要求

在安装之前，请确保您的系统满足以下最低要求：

桌面端

平台最低版本推荐配置
WindowsWindows 10 (21H2+)Windows 11
macOSmacOS 12.0macOS 14.0+
Linux内核 5.4+内核 6.0+

移动端

  • iOS：iOS 16.0+，支持 Apple Watch 配套应用
  • Android：Android 12+（计划中）
  • iPadOS：iPadOS 16.0+，支持分屏和多任务

通用要求

  • 可用磁盘空间：至少 500MB
  • 内存：建议 8GB 以上
  • 网络：稳定的互联网连接（用于 Agent 通信）

安装 Alius Agent Team

macOS 安装

  1. 从官方网站或 App Store 下载 Alius Agent Team
  2. 打开下载的 .dmg 文件
  3. 将 Alius Agent Team 拖入 Applications 文件夹
  4. 首次打开时，系统可能提示”无法验证开发者”，请在”系统设置 > 隐私与安全性”中允许运行

Windows 安装

  1. 下载 .msi 安装包
  2. 双击运行安装程序
  3. 按照安装向导完成安装
  4. 首次运行时，如遇到 Windows Defender 提示，请选择”仍要运行”

Linux 安装

# Debian/Ubuntu
sudo dpkg -i alius-agent-team_x.x.x_amd64.deb
sudo apt-get install -f

# Arch Linux (AUR)
yay -S alius-agent-team

# 通用 Linux (AppImage)
chmod +x Alius-Agent-Team-x.x.x.AppImage
./Alius-Agent-Team-x.x.x.AppImage

首次启动与账户注册

步骤 1：启动应用

安装完成后，启动 Alius Agent Team。您将看到欢迎界面，提供以下登录选项：

  • 短信登录（推荐）
  • Apple ID 登录
  • 微信扫码登录

步骤 2：创建账户或登录

短信登录

  1. 选择”短信登录”
  2. 输入您的手机号码
  3. 点击”获取验证码”
  4. 输入收到的 6 位验证码
  5. 设置用户名和密码（首次使用时）
  6. 点击”登录”

Apple ID 登录

  1. 选择”Apple 登录”
  2. 在弹出的 Apple ID 登录窗口中完成认证
  3. 授权 Alius Agent Team 访问必要的用户信息
  4. 完成登录

微信登录

  1. 选择”微信登录”
  2. 使用微信扫描屏幕上显示的二维码
  3. 在微信中确认登录授权
  4. 完成登录

步骤 3：初始配置向导

首次登录后，系统将引导您完成初始配置：

  1. 工作空间设置：设置默认工作目录
  2. 通知偏好：选择接收通知的方式和频率
  3. Agent 运行环境：配置 Agent 执行的默认环境
  4. 隐私设置：选择数据共享偏好

创建您的第一个 Agent

完成初始配置后，让我们创建第一个 Agent：

方法一：通过界面创建

  1. 在主界面点击”+“或”新建 Agent”按钮
  2. 填写 Agent 基本信息：
    • 名称：为 Agent 取一个易识别的名称
    • 描述：简要描述 Agent 的用途
    • 类型：选择 Agent 类型（通用、代码生成、数据分析等）
    • 运行环境：选择运行环境（本地、远程服务器等）
  3. 配置 Agent 参数：
    • 模型选择：选择底层 AI 模型
    • 温度参数：设置创造性程度
    • 最大令牌数：设置响应长度限制
  4. 点击”创建”完成

方法二：通过向导创建

  1. 选择”快速开始”中的”创建我的第一个 Agent”
  2. 按照向导步骤填写信息
  3. 向导将提供更详细的说明和建议

发送第一个任务

Agent 创建完成后，让我们发送第一个任务：

  1. 在 Agent 列表中点击您刚创建的 Agent
  2. 在底部的任务输入框中输入任务描述
  3. 点击”发送”或按 Ctrl+Enter（macOS 为 Cmd+Enter）
  4. 观察 Agent 的执行过程和结果

示例任务：

请帮我分析以下代码的问题，并提供修复建议：

function add(a, b) {
  return a + b
}

console.log(add(1, 2, 3))

安装移动端应用（可选）

如果您希望在移动设备上管理 Agent：

  1. 在 App Store 搜索”Alius Agent Team”
  2. 下载并安装应用
  3. 使用与桌面端相同的账户登录
  4. 所有 Agent 和任务将自动同步

Apple Watch 应用

如果您使用 iPhone，还可以安装配套的 Apple Watch 应用：

  1. 在 iPhone 上打开 Watch 应用
  2. 在”可用应用”中找到 Alius Agent Team
  3. 点击”安装”
  4. 在 Apple Watch 上打开应用，使用 iPhone 扫码配对

下一步

恭喜！您已经成功安装并配置了 Alius Agent Team，创建了第一个 Agent 并发送了任务。接下来，您可以：

  • 阅读架构文档了解系统设计
  • 学习Agent 管理以掌握高级功能
  • 探索任务管理以高效分配工作
  • 了解团队管理以便与团队协作

如果您遇到任何问题，请查看常见问题或联系我们的支持团队。
