团队管理

团队管理功能使多个用户能够协作管理 Agent 和任务。通过团队功能，您可以实现 Agent 共享、权限管理、协作工作流等高级功能。

团队概念

什么是团队

在 Alius Agent Team 中，团队（Team） 是一组用户和 Agent 的集合。团队成员可以共享 Agent、协同处理任务、共享配置和模板等。

团队的优势

  • 资源共享：团队成员可以共享 Agent，提高资源利用率
  • 协作工作：多人协同处理复杂任务
  • 权限管理：通过角色和权限实现细粒度的访问控制
  • 知识共享：共享提示词模板、配置方案等
  • 统一计费：团队统一付费，简化成本管理

创建团队

创建新团队

步骤 1：发起创建

  1. 在主界面，点击左侧导航栏的”团队”
  2. 点击”创建团队”按钮
  3. 填写团队基本信息：
    • 团队名称：团队的唯一标识名称（必填）
    • 描述：团队的用途说明（可选但推荐）
    • 团队头像：上传团队头像（可选）
  4. 点击”创建”

步骤 2：初始配置

创建完成后，系统将引导您完成初始配置：

  • 可见性设置：
    • 公开：任何用户都可以看到并申请加入
    • 私有：仅邀请可见
  • 加入审批：
    • 自动批准：任何申请都自动通过
    • 需要审批：管理员审批后才能加入
  • 默认权限：设置新成员的默认角色

团队设置

基本信息设置

  • 名称：团队名称（不可重复）
  • 描述：团队的详细说明
  • 标签：便于搜索和分类的标签
  • 联系方式：团队的联系邮箱或链接

高级设置

  • 最大成员数：限制团队规模
  • 最大 Agent 数：限制团队可创建的 Agent 数量
  • 存储配额：限制团队的存储使用量
  • API 调用配额：限制团队的 API 调用次数

管理团队成员

邀请成员

通过邮箱邀请

  1. 进入团队设置页面
  2. 选择”成员管理”
  3. 点击”邀请成员”
  4. 输入对方的邮箱地址
  5. 选择角色（Owner、Admin、Member、Viewer）
  6. 添加邀请消息（可选）
  7. 点击”发送邀请”
  8. 被邀请人将收到邮件通知，点击链接接受邀请

通过链接邀请

  1. 在成员管理页面，点击”生成邀请链接”
  2. 设置链接有效期（1天、7天、30天或永久）
  3. 设置通过链接加入的成员默认角色
  4. 复制链接并分享
  5. 任何有链接的人都可以加入团队

成员角色与权限

Alius Agent Team 提供四级角色体系：

Owner（所有者）

  • 权限：团队的完全控制权
  • 能力：
    • 修改团队设置和删除团队
    • 管理所有成员和角色
    • 管理所有 Agent 和任务
    • 管理计费和订阅
    • 管理团队模板和配置

Admin（管理员）

  • 权限：团队的管理权限，除了删除团队和修改计费
  • 能力：
    • 邀请和管理成员（不能修改 Owner）
    • 管理所有 Agent 和任务
    • 管理团队模板和配置
    • 查看团队统计数据

Member（成员）

  • 权限：团队的普通成员权限
  • 能力：
    • 创建和管理自己的 Agent
    • 参与团队任务
    • 使用团队共享的 Agent 和模板
    • 查看团队基本信息

Viewer（观察者）

  • 权限：只读权限
  • 能力：
    • 查看团队信息
    • 查看团队 Agent 和任务（不能修改）
    • 查看团队统计

修改成员角色

  1. 进入团队设置 > 成员管理
  2. 找到要修改的角色成员
  3. 点击该成员右侧的”角色”下拉菜单
  4. 选择新角色
  5. 确认修改

注意：只有 Owner 和 Admin 可以修改成员角色。

移除成员

  1. 进入团队设置 > 成员管理
  2. 找到要移除的成员
  3. 点击”更多操作” > “移除成员”
  4. 确认移除

注意：

  • 移除成员后，该成员将失去对团队资源的访问权限
  • 该成员创建的 Agent 可以选择：转移给其他人、保留在团队中、或删除
  • Owner 不能被移除（需要先转移所有权）

退出团队

如果您想退出某个团队：

  1. 进入团队设置 > 我的设置
  2. 滚动到页面底部
  3. 点击”退出团队”
  4. 确认退出

注意：退出团队后，您将失去对该团队资源的访问权限。

团队 Agent 管理

共享 Agent

将个人创建的 Agent 共享给团队：

  1. 找到要共享的 Agent
  2. 点击”更多操作” > “共享给团队”
  3. 选择要共享的团队
  4. 设置共享权限：
    • 只读：团队成员可以查看和使用，但不能修改
    • 可编辑：团队成员可以查看、使用和修改
    • 可管理：团队成员拥有完全控制权
  5. 确认共享

团队 Agent 库

团队有一个共享的 Agent 库：

  • 查看：所有团队成员都可以查看团队 Agent 库
  • 使用：根据权限使用团队 Agent
  • 管理：根据权限管理团队 Agent

Agent 使用统计

团队管理员可以查看 Agent 的使用统计：

  • 每个 Agent 被使用的次数
  • 每个成员使用 Agent 的情况
  • Agent 的资源消耗统计

团队协作功能

团队任务

创建团队任务

团队任务是对整个团队可见的任务：

  1. 创建任务时，选择”团队任务”
  2. 选择目标团队
  3. 填写任务信息
  4. 选择任务的可见范围：
    • 团队可见：所有团队成员都可以看到
    • 指定成员可见：仅指定成员可见
  5. 提交任务

任务分配策略

团队任务可以使用以下分配策略：

  • 手动分配：由管理员或创建者手动分配
  • 自荐分配：团队成员可以自荐认领任务
  • 自动分配：系统根据负载和技能自动分配
  • 轮询分配：团队成员轮流认领任务

团队通知

通知设置

团队成员可以设置接收通知的方式：

  • 任务分配通知：当任务分配给您时
  • 任务状态变更通知：当您关注的任务状态变更时
  • Agent 状态通知：当团队 Agent 状态变更时
  • 团队成员变更通知：当有成员加入或离开时

通知渠道

  • 应用内通知：在 Alius Agent Team 应用内显示
  • 邮件通知：发送到注册邮箱
  • 微信通知：通过微信服务号发送（需要绑定）
  • Watch 通知：通过 Apple Watch 推送（需要配对）

团队活动日志

团队管理员可以查看团队的活动日志：

  • 成员加入/离开
  • Agent 创建/修改/删除
  • 任务创建/分配/完成
  • 设置变更

活动日志保留 90 天，可用于审计和问题排查。

团队模板与配置共享

提示词模板共享

团队成员可以共享提示词模板：

  1. 创建或编辑提示词模板
  2. 在”可见性”设置中选择”团队可见”
  3. 保存模板
  4. 所有团队成员都可以使用该模板

配置方案共享

类似地，您可以共享 Agent 配置方案：

  1. 将 Agent 配置保存为方案
  2. 设置方案为”团队可见”
  3. 其他团队成员可以基于该方案快速创建 Agent

团队计费与订阅

计费模式

Alius Agent Team 提供以下计费模式：

  • 按座位数计费：根据团队成员数量计费
  • 按资源计费：根据团队使用的资源（Agent 数量、API 调用次数等）计费
  • 混合计费：基础费用 + 资源使用费

订阅管理

查看当前订阅

  1. 进入团队设置 > 计费与订阅
  2. 查看当前订阅计划
  3. 查看资源使用情况和配额

升级订阅

  1. 在计费页面，点击”升级”
  2. 选择新的订阅计划
  3. 确认付款
  4. 订阅将立即生效

取消订阅

  1. 在计费页面，点击”管理订阅”
  2. 选择”取消订阅”
  3. 确认取消
  4. 订阅将在当前计费周期结束时失效

发票管理

  1. 进入团队设置 > 计费与订阅 > 发票管理
  2. 查看历史发票
  3. 申请开具发票
  4. 设置发票接收邮箱

团队数据导出

导出团队数据

团队 Owner 和 Admin 可以导出团队数据：

  1. 进入团队设置 > 高级 > 数据导出
  2. 选择要导出的数据：
    • 团队基本信息
    • 成员列表
    • Agent 列表和配置
    • 任务历史
    • 活动日志
  3. 选择导出格式（JSON、CSV、PDF）
  4. 点击”导出”
  5. 系统将生成导出文件并发送下载链接

数据保留策略

  • 活跃团队：数据永久保留
  • 已删除团队：数据保留 30 天后永久删除
  • 退出成员：其创建的资源根据设置处理

删除团队

警告：删除团队是永久性操作，不可恢复。

删除前准备

在删除团队之前：

  1. 备份数据：导出重要的团队数据
  2. 处理 Agent：决定团队 Agent 的归属
    • 转移给特定成员
    • 保留为个人 Agent
    • 删除
  3. 通知成员：提前通知团队成员
  4. 结清费用：确保没有未支付的费用

删除步骤

  1. 以 Owner 身份登录
  2. 进入团队设置 > 高级 > 删除团队
  3. 阅读删除警告
  4. 输入团队名称以确认
  5. 点击”永久删除团队”
  6. 团队将被标记为”已删除”，30 天后永久清除数据

最佳实践

团队结构设计

小型团队（< 10人）

  • 1 个 Owner
  • 1-2 个 Admin
  • 其余为 Member
  • 可选：添加 Viewer（如实习生、实习生）

中型团队（10-50人）

  • 1 个 Owner
  • 3-5 个 Admin（分领域负责）
  • 多个 Member（按项目或职能分组）
  • 可选：添加 Viewer

大型团队（50+人）

  • 考虑创建多个子团队
  • 每个子团队有独立的 Owner 和 Admin
  • 建立明确的权限和审批流程

命名规范

建议为团队资源建立命名规范：

Agent 命名：{team}-{project}-{purpose}

示例：
- alius-web-codegen
- alius-mobile-test
- alius-data-analysis

定期审计

建议定期进行团队审计：

  • 成员审计：每季度审查成员列表，移除不活跃成员
  • 权限审计：每季度审查成员权限，确保最小权限原则
  • 资源审计：每月审查 Agent 使用情况，清理不需要的 Agent
  • 安全审计：每月审查活动日志，发现异常行为

常见问题

如何转移团队所有权？

只有当前 Owner 可以转移所有权：

  1. 进入团队设置 > 成员管理
  2. 找到要提升为 Owner 的成员
  3. 将其角色修改为 Owner
  4. 系统将提示您确认转移所有权
  5. 确认后，您将变为 Admin 角色

团队成员数量有限制吗？

取决于您的订阅计划：

  • 免费版：最多 3 名成员
  • 基础版：最多 10 名成员
  • 专业版：最多 50 名成员
  • 企业版：无限制

可以创建多个团队吗？

可以。您可以是多个团队的成员，甚至可以拥有多个团队。
