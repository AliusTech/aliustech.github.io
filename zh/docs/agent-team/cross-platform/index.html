跨平台支持

Alius Agent Team 基于 Tauri 2 构建，真正实现了跨平台支持。无论您使用桌面电脑、平板电脑、手机还是 Apple Watch，都能获得一致且优化的用户体验。

支持的平台

桌面平台

平台最低版本推荐版本支持架构
Windows10 (21H2)11x86_64, ARM64
macOS12.0 (Monterey)14.0 (Sonoma)x86_64, ARM64
Linux内核 5.4内核 6.0x86_64, ARM64

移动平台

平台最低版本推荐版本备注
iOS16.017.0+支持 iPhone 和 iPad
iPadOS16.017.0+支持分屏和多任务
Android12.014.0+开发中
watchOS9.010.0+仅配套功能

桌面端体验

Windows

特性

  • 原生外观：遵循 Windows 11 Fluent Design 设计规范
  • 系统整合：
    • 开始菜单集成
    • 任务栏托盘图标
    • 系统通知中心集成
    • 右键菜单扩展
  • 快捷键：完整的键盘快捷键支持
  • 多窗口：支持多窗口操作
  • 系统主题：自动适应系统主题（浅色/深色）

安装方式

  • Microsoft Store：一键安装和自动更新
  • 独立安装包：.msi 或 .exe 安装程序
  • 便携式版本：无需安装的便携式版本
  • Winget：通过 Windows 包管理器安装
# 使用 Winget 安装
winget install Alius.AgentTeam

系统要求

  • CPU：双核 2.0GHz 或更高
  • 内存：8GB 以上（推荐 16GB）
  • 磁盘空间：2GB 以上可用空间
  • 显卡：支持 DirectX 11 或更高

macOS

特性

  • 原生外观：遵循 macOS Apple Human Interface Guidelines
  • 系统整合：
    • 菜单栏图标
    • 程序坞集成
    • 通知中心集成
    • Spotlight 搜索集成
    • Handoff 接力支持
  • 触控板手势：支持多指手势
  • Universal Binary：同时支持 Intel 和 Apple Silicon

安装方式

  • App Store：一键安装和自动更新
  • 直接下载：.dmg 磁盘镜像文件
  • Homebrew：通过 Homebrew 安装
# 使用 Homebrew 安装
brew install --cask alius-agent-team

系统要求

  • macOS 12.0 (Monterey) 或更高
  • 内存：8GB 以上（推荐 16GB）
  • 磁盘空间：2GB 以上可用空间
  • 网络：宽带互联网连接

权限说明

首次使用时，macOS 可能要求以下权限：

  • 通知：发送系统通知
  • 网络：访问网络
  • 文件访问：访问特定目录
  • 辅助功能：某些高级功能需要

Linux

特性

  • 多发行版支持：支持主流 Linux 发行版
  • 桌面环境适配：
    • GNOME
    • KDE Plasma
    • XFCE
    • Cinnamon
  • 包管理器支持：
    • APT (Debian/Ubuntu)
    • RPM (Fedora/RHEL)
    • Pacman (Arch)
    • AppImage (通用)

安装方式

# Debian/Ubuntu
sudo dpkg -i alius-agent-team_x.x.x_amd64.deb
sudo apt-get install -f

# Fedora/RHEL
sudo rpm -ivh alius-agent-team-x.x.x.x86_64.rpm

# Arch Linux (AUR)
yay -S alius-agent-team

# AppImage (通用)
chmod +x Alius-Agent-Team-x.x.x.AppImage
./Alius-Agent-Team-x.x.x.AppImage

# Snap (开发中)
sudo snap install alius-agent-team

系统要求

  • Linux 内核 5.4 或更高
  • glibc 2.31 或更高
  • 内存：8GB 以上（推荐 16GB）
  • 磁盘空间：2GB 以上可用空间

已知问题

  • Wayland：某些功能在 Wayland 下可能受限
  • 系统托盘：某些桌面环境的系统托盘可能不显示
  • 全局快捷键：某些桌面环境下全局快捷键可能不工作

自适应组件

所有 UI 组件都根据屏幕尺寸自适应：

  • 数据表格：在大屏幕上显示完整表格，在小屏幕上转为卡片列表
  • 表单：在大屏幕上多列布局，在小屏幕上单列布局
  • 图表：根据可用空间自动调整大小和布局
  • 对话框：在大屏幕上居中弹出，在小屏幕上全屏显示

Apple Watch 应用

Alius Agent Team 提供独特的 Apple Watch 应用，让您在手腕上管理 Agent。

功能

快速查看

  • Agent 状态：快速查看所有 Agent 的运行状态
  • 任务概览：查看进行中和待处理的任务
  • 通知：接收和查看系统通知

简单操作

  • 启动/停止 Agent：快速启动或停止 Agent
  • 任务确认：快速确认或拒绝任务分配
  • 语音输入：使用 Siri 创建新任务

健身记录整合

  • 站立提醒：长时间坐着工作时提醒站立
  • 健身记录：记录您的工作时间和活动

设置

配对

  1. 在 iPhone 上打开 Watch 应用
  2. 在”可用应用”中找到 Alius Agent Team
  3. 点击”安装”
  4. 在 Apple Watch 上打开应用
  5. 使用 iPhone 扫码配对

配置

在 iPhone 应用中配置 Watch 应用：

  • 显示选项：选择 Watch 上显示的信息
  • 通知设置：选择推送到 Watch 的通知类型
  • 快捷操作：配置表盘快捷操作

使用场景

会议中

  • 快速查看 Agent 状态，无需拿出手机
  • 接收重要通知的触觉反馈

外出时

  • 接收任务完成通知
  • 快速创建语音任务

演示时

  • 在手表上查看演示用的 Agent 状态
  • 无需操作电脑，避免干扰演示

数据同步

跨设备同步

Alius Agent Team 在所有设备之间实时同步数据：

  • Agent 配置：在所有设备上保持最新
  • 任务状态：实时同步任务状态变更
  • 团队信息：团队成员和权限实时同步
  • 用户偏好：界面设置和偏好设置同步

同步机制

实时同步

  • WebSocket：建立持久连接，实时推送变更
  • 冲突解决：使用”最后写入获胜”策略解决简单冲突
  • 版本控制：复杂冲突通过版本控制解决

离线支持

  • 离线缓存：最近访问的数据缓存到本地
  • 操作队列：离线时的操作排队，联网后同步
  • 增量同步：只同步变更的数据，节省流量

同步设置

在用户设置中配置同步行为：

  • 自动同步：自动同步数据（推荐）
  • 手动同步：仅在点击同步按钮时同步
  • 仅 Wi-Fi 同步：仅在 Wi-Fi 网络下同步
  • 同步频率：设置自动同步的频率

  • 系统托盘：最小化到系统托盘

Watch 独有功能

跨平台开发技术

Tauri 2 架构

Alius Agent Team 使用 Tauri 2 实现跨平台：

前端 (React 19 + TypeScript)
        ↓
    Tauri Core (Rust)
        ↓
  平台抽象层
        ↓
  Windows / macOS / Linux / iOS

优势

  • 体积小：应用体积通常 < 10MB
  • 性能好：Rust 后端提供接近原生的性能
  • 安全：Rust 的内存安全保证
  • 资源占用低：内存和 CPU 占用远低于 Electron

代码共享策略

src/
├── core/              # 纯逻辑代码（跨平台共享）
│   ├── types/        # 类型定义
│   ├── utils/        # 工具函数
│   └── services/     # 业务逻辑
├── platform/
│   ├── desktop/     # 桌面端特定代码
│   ├── mobile/      # 移动端特定代码
│   └── watch/       # Watch 特定代码
└── shared/           # 共享 UI 组件

共享代码比例

  • 逻辑代码：95% 共享
  • UI 组件：70% 共享
  • 平台特定代码：5-30%

  • 在移动端进行快速检查和简单操作
  • 在 Watch 端接收重要通知和进行简单操作

  • 在桌面端使用键盘快捷键提高效率

故障排查

同步问题

问题：数据在一个设备上更新，在其他设备上不显示

解决方法：

  1. 检查网络连接
  2. 手动触发同步
  3. 重启应用
  4. 如果问题持续，联系支持团队

通知问题

问题：在移动设备上收不到推送通知

解决方法：

  1. 检查系统通知设置
  2. 确保应用有发送通知的权限
  3. 检查勿扰模式设置
  4. 重新登录账户

性能问题

问题：应用在某些设备上运行缓慢

解决方法：

  1. 关闭不必要的 Agent
  2. 清理缓存
  3. 更新到最新版本
  4. 如果问题持续，联系支持团队

  • Linux ARM64 支持：支持树莓派等设备
  • Web 版本：通过浏览器访问（只读）

长期计划

  • Android Wear OS 支持：Android 手表应用
  • visionOS 支持：Apple Vision Pro 应用
  • Chromebook 优化：针对 Chromebook 优化

总结

Alius Agent Team 的跨平台支持让您可以在任何设备上高效管理 AI Agent。无论是在办公室的桌面电脑上，还是在路上的手机上，或是在会议中的 Apple Watch 上，您都能获得一致且优化的体验。
