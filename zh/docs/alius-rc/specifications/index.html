概述

本文档提供 Alius RC 遥控器的完整技术规格，包括硬件参数、电气性能、通信协议、机械尺寸和环境适应性指标。适用于系统集成前的技术评估和方案设计。

核心硬件参数

显示屏

参数规格
尺寸7.02 英寸
分辨率1920 × 1200
像素密度323 PPI
亮度1200 nits（峰值）
触摸方式电容式多点触控，支持手套操作
表面处理防指纹、防反射镀膜

处理器与存储

参数规格
SoCQualcomm Snapdragon 865 (SM8250)
CPU8核 Kyro 585，最高 2.84 GHz
GPUAdreno 650
RAM8 GB LPDDR5
内部存储128 GB UFS 3.1
外部存储支持 microSD 扩展（最高 512 GB）

操控组件

部件规格
摇杆 ×2霍尔效应传感器，无漂移设计，分辨率 4096 级
波轮金属材质，带阻尼，1024 级精度
自定义按键 C1/C2可编程，支持单击/双击/长按
录制键独立物理按键
五维导航键上下左右 + 按下的 5D 摇杆
返回/主页按键触控式

通信系统

OcuSync 4.0 图传

参数规格
最大传输距离20 km (FCC) / 12 km (CE/SRRC)
工作频率2.400 - 2.4835 GHz, 5.725 - 5.850 GHz
视频传输分辨率1080p/60fps, 1080p/50fps, 720p/60fps
最大码率50 Mbps
端到端延迟< 50 ms（理想条件）
天线4 天线，2T4R
自动跳频支持，双频自适应切换

其他通信方式

协议参数
WiFi 6 (802.11ax)2.4 GHz + 5 GHz 双频，MIMO 2×2
蓝牙 5.2支持 BLE 和 BR/EDR
4G (可选)LTE Cat.18，Nano SIM
GNSSGPS + GLONASS + BeiDou + Galileo

扩展接口

物理接口

接口位置功能描述
USB-C (主机)底部USB 3.1 Gen2, 10Gbps, DP Alt Mode 视频输出, 支持 PD 快充
HDMI 2.0底部最高 4K@60Hz 输出，支持外接显示器/头戴显示器
自定义数据接口底部（专用触点）预留 CAN、UART、GPIO，供深度定制使用
microSD 卡槽机身侧面（防水盖内）最大 512 GB
Nano SIM 卡槽背部（需拆盖）仅 4G 版本
3.5mm 音频接口底部CTIA 标准耳机/麦克风

自定义数据接口引脚定义

自定义数据接口通过底部专用触点引出，供高级用户进行深度硬件集成：

引脚信号描述
1CAN_HCAN 总线高电平
2CAN_LCAN 总线低电平
3UART_TX串口发送 (3.3V TTL)
4UART_RX串口接收 (3.3V TTL)
5GPIO_1可编程 GPIO (3.3V)
6GPIO_2可编程 GPIO (3.3V)
7VBUS_5V5V/1A 对外供电
8GND地

使用自定义接口需要专用扩展底座（需另行购买）。不正确的接线可能损坏设备，请务必参考详细的硬件集成文档。

电源与电池

参数规格
电池类型锂聚合物电池
电池容量5000 mAh (典型值)
标称电压7.2V
充电功率最大 30W (USB PD 3.0)
充电时间约 2 小时 (0% → 100%)
续航时间约 3 小时（满亮度、持续操控）
外接供电支持 USB-C 边充边用，也可通过扩展底座供电

续航优化建议

  • 适当降低屏幕亮度（推荐户外 80%，室内 50%）
  • 关闭不需要的无线通信模块（蓝牙、4G）
  • 在 Alius RC Manager 中启用省电模式
  • 携带移动电源或备用电池以延长野外工作时间

软件平台

参数详情
操作系统Android 10 (Alius 定制版)
API Level29
预装 SDKDJI MSDK 5.10.x + Alius RC SDK 1.2.x
开发语言Java, Kotlin
开发工具Android Studio Arctic Fox+
系统更新OTA 在线更新 + 本地刷机包
Root 权限默认关闭，开发者可申请开启

环境适应性

参数规格
防护等级IP54（防尘、防溅水）
工作温度-20°C 至 50°C
存储温度-30°C 至 60°C（电池存储建议 22°C 至 30°C）
工作湿度5% 至 95% RH（无冷凝）
抗跌落1.0m 混凝土面跌落（6面）
ESD 防护±8kV 接触放电，±15kV 空气放电

重要提示：IP54 防护等级不意味着设备可以浸泡在水中。请勿在大雨中使用超过 30 分钟，使用后请擦干接口处的积水。

机械规格

参数规格
外形尺寸185 × 145 × 75 mm（不含天线突起）
重量约 680g（含电池）
外壳材质PC + ABS 工程塑料，橡胶包边
天线内置双频天线，折叠式外置天线（可选高增益天线）
挂绳孔支持，底部两侧预留

指标数值
