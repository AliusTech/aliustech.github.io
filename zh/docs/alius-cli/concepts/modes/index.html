首页 / 文档 / Alius CLI / Chat 与 Plan 模式

两种模式，一个引擎

Alius 使用统一的 Loop Engine 配合两种策略：

  • Chat 模式 = Loop Engine + ChatPolicy
  • Plan 模式 = Loop Engine + PlanPolicy

两种模式共享相同的底层运行时、协议接口和记忆系统。

Chat 模式

单轮交互，适用于快速任务：

Alius[chat] gpt-4o-mini > 解释这个函数
Alius[chat] gpt-4o-mini > 认证中间件做了什么？

适用于：

  • 问答和解释
  • 快速查询和澄清
  • 轻量代码生成
  • 一次性分析

Chat 模式默认运行单轮，不自动激活工具。

Plan 模式

多步骤规划和执行，适用于复杂任务：

Alius[chat] gpt-4o-mini > /mode plan
Alius[plan] gpt-4o-mini > 重构认证模块以支持 OAuth2

适用于：

  • 功能实现
  • 代码重构
  • 多文件变更
  • 复杂调试

Plan 模式生成结构化计划、按序执行步骤、使用工具并检查收敛。

切换模式

/mode          # 显示当前模式
/mode chat     # 切换到 Chat 模式
/mode plan     # 切换到 Plan 模式

或使用 Shift+Tab 键盘快捷键。

Plan 模式工作流程

  1. 你描述目标
  2. Alius 生成包含明确步骤的计划
  3. 每个步骤通过运行时执行
  4. 工具调用经过 Shell Gate 审批
  5. 结果被记录和追踪
  6. 计划收敛或请求澄清

两种模式中的安全性

无论哪种模式，所有工具操作都经过 Shell Gate：

  • 敏感操作需要你明确审批
  • 可以为信任的操作配置自动审批规则
  • 所有决策被记录用于审计
