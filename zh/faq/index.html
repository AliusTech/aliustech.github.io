常见问题解答

关于 Alius 产品、硬件、软件和部署的常见问题。

1 产品

Alius 是什么？

Alius 是一个具身智能平台，提供从机器人硬件（关节模组、DCU 控制器、CAN 调试器）到 AI Agent 软件（Alius CLI、Agent Team）的完整技术栈。它为构建真实机器人的团队而设计——不仅仅是软件 Agent。

Alius 是开源的吗？

是的。Alius CLI 和核心软件栈是开源的（Rust，MIT/Apache-2.0）。硬件设计和驱动也在 GitHub 上开放。我们相信最好的基础设施是每个人都可以检查和信任的。

2 硬件

Alius 硬件兼容哪些机器人？

Alius 硬件（关节模组、DCU）为定制机器人设计——仿人机器人、四足机器人和工业手臂。模块使用标准 CAN/CAN-FD 和 EtherCAT 通信，可与任何支持这些标准的机器人平台集成。

Alius 硬件使用什么通信协议？

关节模组：CAN 2.0B / CAN-FD，RS-485。Robot DCU：CAN-FD，RS-485，EtherCAT，以太网，USB 3.0。USB2CAN：USB 2.0 转双路 CAN/CAN-FD。动捕系统：WiFi UDP。所有协议均为标准协议并有文档。

3 软件

可以不使用 Alius 硬件单独使用 Alius CLI 吗？

完全可以。Alius CLI 是一个独立的 AI Agent 运行时，可在 macOS 和 Linux 上运行。它专为需要结构化、可追踪 AI Agent 执行的开发者设计——无论你是在控制机器人还是构建软件。

Alius CLI 和 Agent Team 有什么区别？

Alius CLI 是本地开发工具，用于从终端运行单个 AI Agent。Agent Team 是服务端平台，用于管理多个 Agent、任务队列、审批工作流和团队协作——配备桌面端、平板和手机的跨平台控制台。

4 部署与集成

如何将 Alius 部署到 Robot DCU？

Robot DCU 运行 Linux 发行版（Debian/Ubuntu/Buildroot）。Alius CLI 可以使用 Rust 的交叉编译工具链为 ARM64（RK3588S 目标）交叉编译。对于实时控制，DCU 运行 RTOS 与 Linux 并行——Alius 通过标准接口通信。

Alius 适合生产环境机器人部署吗？

Alius 专为生产环境设计。硬件按工业环境标准打造（IP54 防护、隔离电源、工业接口）。软件栈具有 Shell Gate 安全、完整审计日志和确定性执行——这些都是生产部署所需的特性。
