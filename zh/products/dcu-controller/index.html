硬件 · 域控制器

机器人 DCU 域控制器

基于 RK3588S SoC 的高性能域控制单元。实时控制与 Linux 用户态异构计算，为智能机器人量身打造的中央神经系统。

取得联系

核心特性

机器人的大脑——实时处理传感器数据、运行 AI 模型和控制执行器。

异构计算

RK3588S SoC 集成四核 A76 + 四核 A55、Mali-G610 GPU 和 6 TOPS NPU。在单芯片上同时运行实时控制和 AI 推理。

丰富工业接口

CAN/CAN-FD、RS-485、EtherCAT、以太网、USB 3.0、MIPI-CSI/DSI。无需外部适配器即可连接传感器、执行器和显示器。

隔离电源设计

CAN 和 RS-485 收发器采用电气隔离设计，配合隔离电源。在工业环境中抵御地环路和电压尖峰。

实时 + Linux

实时控制任务在专用核心上运行，确保确定性延迟；同时 Linux 处理高层规划、AI 推理和通信。

技术规格

SoC
Rockchip RK3588S
CPU
四核 A76 @ 2.4 GHz + 四核 A55 @ 1.8 GHz
GPU
Mali-G610 MC4, OpenGL ES 3.2 / Vulkan 1.1
NPU
6 TOPS (INT8), 支持 TensorFlow/PyTorch/ONNX
内存
8/16 GB LPDDR4x
接口
2× CAN-FD, 2× RS-485, 2× EtherCAT, GbE, USB 3.0, MIPI-CSI×2, MIPI-DSI
操作系统
Linux (Debian/Ubuntu/Buildroot) + RTOS 协处理
供电
9–36 VDC 宽范围输入

应用场景

任何自主机器人系统的中央智能枢纽。

仿人机器人控制

中央控制器统一管理所有关节模组、传感器融合、步态规划和基于 AI 的决策。

自主移动机器人

SLAM、路径规划、避障和车队调度，适用于仓储机器人、配送车辆和巡检平台。

工业机器人手臂

实时轨迹规划、力控和视觉引导操作，适用于协作和工业机器人手臂。
