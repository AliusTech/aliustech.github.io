Configuration Overview

Alius stores project configuration in .alius/config/. Each file handles a specific concern:

FilePurpose
config.tomlMain configuration (provider, model, language)
providers.tomlLLM provider endpoints and API keys
soul.tomlAgent identity and role configuration
tools.tomlAvailable tools and capabilities
permissions.tomlSecurity and Shell Gate rules
protocol.tomlProtocol interface settings
mcp.jsonMCP server connections

Main Configuration

config.toml controls the runtime defaults:

[general]
provider = "openai"
model = "gpt-4o"
language = "en"

[session]
auto_save = true
max_context_turns = 20

Provider Configuration

providers.toml defines your LLM connections:

[openai]
api_key_env = "OPENAI_API_KEY"
base_url = "https://api.openai.com/v1"
models = ["gpt-4o", "gpt-4o-mini"]

[anthropic]
api_key_env = "ANTHROPIC_API_KEY"
base_url = "https://api.anthropic.com"
models = ["claude-sonnet-4-6", "claude-haiku-4-5"]

Soul Configuration

soul.toml defines the Agent’s identity:

[soul]
role = "senior-engineer"
description = "A senior software engineer focused on clean code and testing"
language = "en"

Changing Configuration

Interactive Config Panel

/config          # Open configuration panel
/config show     # Display current configuration

Environment Variables

Override settings without modifying files:

export ALIUS_PROVIDER=anthropic
export ALIUS_MODEL=claude-sonnet-4-6

Command-Line Overrides

alius --model gpt-4o-mini --provider openai

Validation

Check that your configuration is complete:

alius config validate

This verifies provider settings, API keys, model availability, and Soul configuration.

Security Note

API keys are referenced through environment variables, never stored in plain text. The config show command masks sensitive values.
