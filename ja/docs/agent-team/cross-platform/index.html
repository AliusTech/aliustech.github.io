クロスプラットフォームサポート

Alius Agent TeamはTauri 2で構築され、真のクロスプラットフォームサポートを実現しています。デスクトップコンピュータ、タブレット、携帯電話、またはApple Watchのいずれを使用しても、一貫して最適化されたユーザー体験を得られます。

デスクトップ体験

Windows

特徴

  • ネイティブ外観：Windows 11 Fluent Design設計ガイドラインに従う
  • システム統合：
    • スタートメニュー統合
    • タスクバートレイアイコン
    • システム通知センター統合
    • 右クリックメニュー拡張
  • ショートカットキー：完全なキーボードショートカットをサポート
  • マルチウィンドウ：マルチウィンドウ操作をサポート
  • システムテーマ：システムテーマに自動適応（ライト/ダーク）

インストール方法

  • Microsoft Store：ワンクリックインストールと自動更新
  • 独立インストーラ：.msiまたは.exeインストーラ
  • ポータブル版：インストール不要のポータブル版
  • Winget：Windowsパッケージマネージャ経由でインストール
# Wingetでインストール
winget install Alius.AgentTeam

システム要件

  • CPU：デュアルコア 2.0GHz以上
  • メモリ：8GB以上（16GB推奨）
  • ディスク容量：2GB以上の空き容量
  • グラフィック：DirectX 11以上をサポート

macOS

特徴

  • ネイティブ外観：macOS Apple Human Interface Guidelinesに従う
  • システム統合：
    • メニューバーアイコン
    • Dock統合
    • 通知センター統合
    • Spotlight検索統合
    • Handoffサポート
  • トラックパッドジェスチャー：多指ジェスチャーをサポート
  • Universal Binary：IntelとApple Siliconを両方サポート

インストール方法

  • App Store：ワンクリックインストールと自動更新
  • 直接ダウンロード：.dmgディスクイメージファイル
  • Homebrew：Homebrew経由でインストール
# Homebrewでインストール
brew install --cask alius-agent-team

システム要件

  • macOS 12.0 (Monterey)以上
  • メモリ：8GB以上（16GB推奨）
  • ディスク容量：2GB以上の空き容量
  • ネットワーク：ブロードバンドインターネット接続

権限説明

初回使用時に、macOSは以下の権限を要求する場合があります：

  • 通知：システム通知を送信
  • ネットワーク：ネットワークにアクセス
  • ファイルアクセス：特定ディレクトリにアクセス
  • アクセシビリティ：一部の高度な機能が必要

Linux

特徴

  • 多ディストリビューションサポート：主要Linuxディストリビューションをサポート
  • デスクトップ環境適応：
    • GNOME
    • KDE Plasma
    • XFCE
    • Cinnamon
  • パッケージマネージャサポート：
    • APT (Debian/Ubuntu)
    • RPM (Fedora/RHEL)
    • Pacman (Arch)
    • AppImage (汎用)

インストール方法

# Debian/Ubuntu
sudo dpkg -i alius-agent-team_x.x.x_amd64.deb
sudo apt-get install -f

# Fedora/RHEL
sudo rpm -ivh alius-agent-team-x.x.x.x86_64.rpm

# Arch Linux (AUR)
yay -S alius-agent-team

# AppImage (汎用)
chmod +x Alius-Agent-Team-x.x.x.AppImage
./Alius-Agent-Team-x.x.x.AppImage

# Snap (開発中)
sudo snap install alius-agent-team

システム要件

  • Linuxカーネル 5.4以上
  • glibc 2.31以上
  • メモリ：8GB以上（16GB推奨）
  • ディスク容量：2GB以上の空き容量

既知の問題

  • Wayland：Wayland環境下で一部の機能が制限される場合がある
  • システムトレイ：一部のデスクトップ環境でシステムトレイが表示されない場合がある
  • グローバルショートカット：一部のデスクトップ環境でグローバルショートカットが動作しない場合がある

Apple Watchアプリ

Alius Agent Teamは、独自のApple Watchアプリを提供し、手首でエージェントを管理できます。

機能

クイックビュー

  • エージェントステータス：すべてのエージェントの実行ステータスを迅速確認
  • タスク概要：進行中および保留中のタスクを閲覧
  • 通知：システム通知を受信および閲覧

簡単操作

  • エージェント起動/停止：エージェントを迅速に起動または停止
  • タスク確認：タスク割り当ての確認または拒否を迅速に実行
  • 音声入力：Siriを使用して新しいタスクを作成

フィットネス統合

  • スタンドリマインダー：長時間座って作業しているときにスタンドをリマインダー
  • フィットネス記録：作業時間と活動を記録

設定

ペアリング

  1. iPhoneでWatchアプリを開く
  2. 「利用可能なApp」でAlius Agent Teamを見つける
  3. 「インストール」をクリック
  4. Apple Watchでアプリを開く
  5. iPhoneでQRコードをスキャンしてペアリング

設定

iPhoneアプリでWatchアプリを設定：

  • 表示オプション：Watchに表示する情報を選択
  • 通知設定：Watchにプッシュする通知タイプを選択
  • クイックアクション：時計画面のクイックアクションを設定

使用シナリオ

会議中

  • 手首でエージェントステータスを迅速確認、携帯電話を出す必要なし
  • 重要な通知の触覚フィードバックを受信

外出時

  • タスク完了通知を受信
  • 音声タスクを迅速に作成

プレゼンテーション中

  • 手首でプレゼンテーション用エージェントステータスを閲覧
  • コンピュータ操作を回避、プレゼンテーションの邪魔を防止

データ同期

クロスデバイス同期

Alius Agent Teamは、すべてのデバイス間でリアルタイムデータ同期：

  • エージェント設定：すべてのデバイスで最新状態を維持
  • タスクステータス：タスクステータス変更をリアルタイム同期
  • チーム情報：チームメンバーと権限をリアルタイム同期
  • ユーザー設定：インターフェース設定と設定を同期

同期メカニズム

リアルタイム同期

  • WebSocket：永続接続を確立、変更をリアルタイムプッシュ
  • コンフリクト解決：簡単なコンフリクトに「最後書き込み勝者」戦略を使用
  • バージョン制御：複雑なコンフリクトをバージョン制御で解決

オフラインサポート

  • オフラインキャッシュ：最近アクセスしたデータをローカルにキャッシュ
  • 操作キュー：オフライン時の操作をキューに格納、オンライン時に同期
  • 増分同期：変更されたデータのみ同期、帯域を節約

同期設定

ユーザー設定で同期動作を設定：

  • 自動同期：自動的にデータを同期（推奨）
  • 手動同期：同期ボタンをクリック時のみ同期
  • Wi-Fiのみ同期：Wi-Fiネットワーク下のみ同期
  • 同期頻度：自動同期の頻度を設定

  • デスクトップでキーボードショートカットを使用して効率を向上
  • モバイルで生体認証を使用して迅速にログイン

トラブルシューティング

同期問題

問題：データが1つのデバイスで更新されたが、他のデバイスに表示されない

解決方法：

  1. ネットワーク接続を確認
  2. 手動で同期をトリガー
  3. アプリを再起動
  4. 問題が続く場合、サポートチームに連絡

通知問題

問題：モバイルデバイスでプッシュ通知を受け取れない

解決方法：

  1. システム通知設定を確認
  2. アプリに通知送信権限があることを確認
  3. マナーモード設定を確認
  4. アカウントに再ログイン

パフォーマンス問題

問題：一部のデバイスでアプリの動作が遅い

解決方法：

  1. 不要なエージェントを閉じる
  2. キャッシュをクリア
  3. 最新バージョンに更新
  4. 問題が続く場合、サポートチームに連絡

まとめ

Alius Agent Teamのクロスプラットフォームサポートにより、任意のデバイスでAIエージェントを効率的に管理できます。オフィスのデスクトップコンピュータ、外出中の携帯電話、会議中のApple Watchのいずれでも、一貫して最適化された体験を得られます。
