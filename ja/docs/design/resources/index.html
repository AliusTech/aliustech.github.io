ホーム / ドキュメント / デザインシステム / リソースライブラリ

リソースライブラリは、Alius コミュニティにダウンロード可能なアセット、デザインファイル、ドキュメント素材、ソフトウェアパッケージを提供します。公式アセットを必要とする開発者、デザイナー、コントリビューター、ベンダーにサービスを提供します。

リソースタイプ

デザインアセット

  • ブランドガイドラインドキュメント（PDF）
  • ロゴファイル（SVG、複数サイズの PNG、ワードマークあり/なし）
  • カラーパレットファイル（ASE、CLR、Sketch パレット）
  • アイコンライブラリ（SVG セット、アイコンフォント）
  • UI キット / コンポーネントライブラリ（Figma、Sketch）
  • テンプレートファイル（プレゼンテーション、ドキュメント、ソーシャルメディア）

ソフトウェアダウンロード

  • CLI インストーラー（macOS、Linux、Windows）
  • SDK パッケージ（Python、JavaScript、ROS）
  • ファームウェアファイル（ハードウェア製品用）
  • 設定テンプレート
  • サンプルプロジェクトとスターターキット

ハードウェアリソース

  • 3D プリント可能ファイル（STL、OBJ）
  • CAD モデル（STEP、Fusion 360）
  • 回路図（PDF、KiCad）
  • 部品表（BOM）
  • 組立手順書（PDF、インタラクティブ）
  • 寸法図面

ドキュメントリソース

  • API リファレンス（オフライン PDF）
  • はじめにガイド（PDF）
  • データシート
  • ホワイトペーパーと技術レポート
  • 変更履歴とリリースノート

ダウンロードページ構造

リソースダウンロードページは一貫した構造に従うべきです：

カテゴリーナビゲーション

  • タイプ別にリソースをグループ化（デザイン、ソフトウェア、ハードウェア、ドキュメント）
  • 製品、バージョン、フォーマットによるフィルタリングを許可
  • 各カテゴリーのリソース総数を表示

リソースカード

各リソース項目には以下を表示：

  • リソース名
  • 簡単な説明
  • 利用可能なファイルフォーマット
  • ファイルサイズ
  • バージョン番号
  • 最終更新日
  • ダウンロードボタン
  • プレビューオプション（該当する場合 — 画像、PDF）

バージョン表示

  • 現在/最新バージョンを目立つように表示
  • ベータまたはプレリリースバージョンはタグで示す
  • バージョン履歴リストから以前のバージョンへのアクセスを許可
  • 非推奨バージョンには警告を付ける

バージョン管理

バージョン命名

  • セマンティックバージョニングに従う（MAJOR.MINOR.PATCH）
  • プレリリースバージョンはサフィックスを使用：-alpha.1、-beta.2、-rc.1
  • すべてのリソースで一貫してバージョン番号を表示

リリースプロセス

  • 各リリースには変更履歴エントリが必要
  • リソースはリリースバージョンでタグ付け
  • ユーザーはリリース通知をサブスクライブ可能
  • 古いバージョンは引き続きアクセス可能だが、非現在として明確にマーク

互換性追跡

  • 特定のソフトウェアまたはハードウェアバージョンに依存するリソースは互換性を宣言する必要がある
  • 互換性マトリクスを使用して、どのリソースバージョンがどの製品バージョンで動作するかを表示
  • メジャーバージョン変更で破壊的変更が導入される場合、アップグレードガイドを提供

アクセス制御

  • ほとんどのリソースはオープンソースミッションをサポートするため公開アクセス可能
  • 一部のリソース（ベンダー素材、内部テンプレート）は認証が必要な場合がある
  • 各リソースのライセンス条件を明確に伝える（MIT、CC-BY、プロプライエタリ）
