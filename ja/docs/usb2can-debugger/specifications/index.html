技術仕様

このドキュメントでは、Alius USB2CANデュアルチャンネルデバッガーの技術仕様を詳細に説明します。ハードウェアパラメーター、性能指標、電気特性、環境要件を含みます。この情報は、システム統合、互換性評価、アプリケーション設計にとって非常に重要です。

ハードウェア仕様

プロセッサー

  • モデル：ARM7（STR750FV2）
  • アーキテクチャ：32ビットRISC
  • クロック速度：特定のモデルによって異なります
  • 機能：CANメッセージの受信、送信、フィルタリング、処理、およびUSB通信管理を担当

メモリー

  • フラッシュ：ファームウェアとプログラムコードの保存に使用
  • RAM：ランタイムデータストレージとバッファー管理に使用

CANインターフェース

  • チャンネル数：2つの独立チャンネル
  • コネクタータイプ：DB9 female（チャンネルごとに1つ）
  • プロトコルサポート：
    • CAN 2.0A（11ビット識別子）
    • CAN 2.0B（29ビット識別子）
  • ボーレート範囲：10 Kbit/s - 1000 Kbit/s
  • ボーレート設定：ソフトウェアで設定可能、標準および非標準ボーレートをサポート
  • 受信フィルター：ハードウェア受信フィルター、シングルフィルターとデュアルフィルターモードをサポート
  • 動作モード：通常モード、ループバックモード、サイレントモード

USBインターフェース

  • インターフェースタイプ：USB 2.0 Type B
  • 転送速度：フルスピード（12 Mbit/s）
  • 電源供給：USBバス給電
  • ケーブル長：3メートル以下のUSBケーブルの使用を推奨

電気絶縁

  • 絶縁電圧：500V（標準）
  • 絶縁タイプ：光学的絶縁または磁気絶縁（特定のモデルによって異なります）
  • 絶縁側：CANバス側はUSB/コンピューター側から完全に絶縁されています
  • 保護機能：グランドループ、電圧サージ、静電放電を防止

性能指標

CAN通信性能

  • 最大メッセージ速度：
    • 500 Kbit/s時：最大5000フレーム/秒（メッセージ長による）
    • 1000 Kbit/s時：最大10000フレーム/秒（メッセージ長による）
  • メッセージバッファー：
    • 受信バッファー：ハードウェアFIFO + ソフトウェアバッファー
    • 送信バッファー：ハードウェアFIFO + ソフトウェアバッファー
  • タイムスタンプ解像度：1 ms（標準）
  • 遅延：
    • 受信遅延：< 1 ms（バスからUSBへ）
    • 送信遅延：< 1 ms（USBからバスへ）

USB通信性能

  • データスループット：
    • アップリンク（デバイスからホストへ）：最大1 MByte/s
    • ダウンリンク（ホストからデバイスへ）：最大1 MByte/s
  • 転送遅延：< 2 ms（標準）

電気特性

電源要件

  • 供給電圧：USBポートを通じて給電（5V DC）
  • 動作電流：
    • シングルチャンネル動作時：< 150 mA
    • デュアルチャンネル動作時：< 200 mA
  • 電源保護：過電流保護、逆電圧保護

CANバス電気特性

  • CANトランシーバー：
    • ISO 11898-2規格に準拠
    • 高速CANをサポート（最大1 Mbit/s）
  • 入力電圧範囲：
    • CAN-H：-27V〜+40V
    • CAN-L：-27V〜+40V
  • コモンモード電圧範囲：-2V〜+7V
  • 終端抵抗：外部120Ω終端抵抗が必要（バス両端に1つずつ）

絶縁特性

  • 絶縁電圧：500V DC（連続）
  • 絶縁抵抗：> 100 MΩ（500V DC時）
  • 絶縁容量：< 10 pF（標準）
  • サージ保護：IEC 61000-4-5規格に準拠

環境要件

動作温度

  • 商業グレード：0°C〜+70°C
  • 産業グレード：-40°C〜+85°C（特定のモデルによって異なります）

保存温度

  • 範囲：-40°C〜+85°C

湿度

  • 動作湿度：10%〜90% RH（非結露）
  • 保存湿度：5%〜95% RH（非結露）

高度

  • 動作高度：最大2000メートル
  • 保存高度：最大12000メートル

電磁両立性（EMC）

  • 放射エミッション：EN 55022 Class Bに準拠
  • イミュニティ：EN 61000-6-2に準拠
  • 静電放電（ESD）：IEC 61000-4-2に準拠（±8kV接触放電、±15kV空気放電）

機械仕様

寸法

  • 長さ：特定のモデルによって異なります（通常80-100 mm）
  • 幅：特定のモデルによって異なります（通常40-50 mm）
  • 高さ：特定のモデルによって異なります（通常20-30 mm）
  • 重量：< 100 g

筐体

  • 材料：難燃性ABSプラスチックまたは金属
  • 色：黒または青（特定のモデルによって異なります）
  • 取り付け方法：デスクトップ設置またはDINレール取り付け（特定のモデルによって異なります）

コネクター

  • USBコネクター：USB Type Bメスレセプタクル
  • CANコネクター：2 x DB9メスレセプタクル
  • インジケーター：LEDインジケーター（電源、CANアクティビティ、エラー）

ソフトウェアサポート

ドライバー

  • Windows：Windows 2000/XP/Vista/7/10/11をサポート
  • Linux：主要なディストリビューションをサポート（Ubuntu、Debian、Fedora、CentOSなど）

APIインターフェース

  • CANAL API：オープンソースCANAL API DLL、複数のプログラミング言語をサポート
  • サポート言語：C/C++、C#、Python、Java、LabVIEWなど
  • サンプルコード：複数のプログラミング言語のサンプルコードを提供

認証と標準

  • CE認証：EU CE認証要件に準拠
  • FCC認証：米国FCC Part 15 Class Bに準拠
  • RoHS：RoHS環境要件に準拠
  • WEEE：WEEEリサイクル要件に準拠

注文情報

Alius USB2CANデュアルチャンネルデバッガーは、異なる顧客のニーズを満たすために複数のモデルで提供されています：

  • 標準版：商業グレード温度範囲、実験室およびオフィス環境に適しています
  • 産業版：産業グレード温度範囲、過酷な産業環境に適しています
  • OEM版：筐体なしバージョン、システム統合に適しています

保証情報

  • 保証期間：購入日から1年間
  • 保証範囲：材料および製造上の欠陥
  • 対象外：人為的な損傷、静電放電損傷、仕様を超えた使用による損傷

これらの技術仕様は、予告なく変更される場合があります。注文前に、Alius技術サポートチームに最新の仕様情報を確認してください。
