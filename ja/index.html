コアアーキテクチャ

Session · Run · Trace

すべてのエージェントインタラクションは構造化された実行モデルを通過します。Session が Run を含み、Run が Trace を生成します。これにより、すべてのレベルで完全な制御と可観測性を提供。

01

Session 管理

ステートフルメモリによる永続的な会話コンテキスト。前回終了した場所から再開。

02

Run 実行

ステップバイステップの進捗追跡とエラーリカバリを備えた構造化プラン実行。

03

Trace 可観測性

エージェントの決定、ツール呼び出し、出力の完全な監査証跡。人間のようにデバッグ。
