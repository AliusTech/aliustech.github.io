ロボット DCU ドメインコントローラー

RK3588S SoC ベースの高性能ドメイン制御ユニット。リアルタイム制御と Linux ユーザースペースのヘテロジニアスコンピューティング。知能ロボットの中枢神経系として設計。

ご連絡ください

主な特長

ロボットの脳——センサーデータの処理、AI モデルの実行、アクチュエータのリアルタイム制御を同時実行。

ヘテロジニアスコンピューティング

RK3588S SoC はクアッドコア A76 + クアッドコア A55、Mali-G610 GPU、6 TOPS NPU を統合。単一チップでリアルタイム制御と AI 推論を同時実行。

豊富な産業用インターフェース

CAN/CAN-FD、RS-485、EtherCAT、イーサネット、USB 3.0、MIPI-CSI/DSI。外部アダプタなしでセンサー、アクチュエータ、ディスプレイに接続。

絶縁電源設計

CAN および RS-485 トランシーバーはガルバニック絶縁設計、絶縁電源を搭載。産業環境でのグラウンドループや電圧スパイクから保護。

リアルタイム + Linux

リアルタイム制御タスクは専用コアで確定的レイテンシを実現し、Linux は高レベル計画、AI 推論、通信を処理。

仕様

SoC
Rockchip RK3588S
CPU
クアッドコア A76 @ 2.4 GHz + クアッドコア A55 @ 1.8 GHz
GPU
Mali-G610 MC4, OpenGL ES 3.2 / Vulkan 1.1
NPU
6 TOPS (INT8), TensorFlow/PyTorch/ONNX 対応
メモリ
8/16 GB LPDDR4x
インターフェース
2× CAN-FD, 2× RS-485, 2× EtherCAT, GbE, USB 3.0, MIPI-CSI×2, MIPI-DSI
OS
Linux (Debian/Ubuntu/Buildroot) + RTOS 協調処理
電源
9～36 VDC ワイドレンジ入力

用途

あらゆる自律ロボットシステムの中枢インテリジェンスハブ。

ヒューマノイドロボット制御

すべての関節モジュール、センサフュージョン、歩行計画、AI ベースの意思決定を統合管理するセントラルコントローラー。

自律移動ロボット

SLAM、経路計画、障害物回避、フリート調整。倉庫ロボット、配送車両、点検プラットフォームに対応。

産業用ロボットアーム

リアルタイム軌道計画、力制御、ビジョンガイド操作。協働および産業用ロボットアームに対応。
